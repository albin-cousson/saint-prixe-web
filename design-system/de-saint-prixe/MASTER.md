## Design System: De Saint Prixe

Hand-written from the project's real, already-implemented design — not generated by `--design-system` search. This site's brand was extracted from the live Wix site it replaced (see `src/styles/global.css` header comment and `CLAUDE.md`), not invented, and this file documents that source of truth rather than proposing a new one. Do not overwrite it with a fresh `--design-system --persist` run; if this project's real look ever changes, edit this file by hand to match.

### Pattern
- **Name:** Content showcase + inquiry funnel (not a landing-page/conversion product)
- **Sections:** Home (hero + rotating content sections), roster listings (Nos Chiens/Mâles/Femelles), pedigree detail pages, breeding-pair ("Mariages") detail pages, dated article listing (Actualités), About, Contact
- **Conversion Focus:** A visitor trusts the kennel enough to inquire about a puppy via Contact, or recognizes the kennel's results within the show-circuit community — not a hard sales funnel

### Style
- **Name:** Restrained heritage kennel — real photography and typography over decoration
- **Mode Support:** Light only (no dark mode)
- **Keywords:** sharp corners, generous whitespace, pedigree transparency, editorial restraint, small heart-flourish signature, French dog-show vocabulary
- **Best For:** This project only — do not treat as a reusable category template
- **Performance:** Static Astro build, Sanity CDN images with `auto('format')` (WebP/AVIF)
- **Accessibility:** WCAG AA targeted (contrast ratios below were re-tuned for this — see notes)

### Colors
| Role | Hex | CSS Variable |
|------|-----|--------------|
| Ink (text/dark surfaces) | `#3b3b3b` | `--color-ink` |
| Cream (light surfaces) | `#faf8f0` | `--color-cream` |
| Border | `#e7dfd8` | `--color-border` |
| Gold (fills/borders/text-on-dark) | `#d9b280` | `--color-gold` |
| Gold Deep | `#b9895a` | `--color-gold-deep` |
| Gold Text (text-on-light only) | `#8a5a2b` | `--color-gold-text` |
| Muted | `#6b6a68` | `--color-muted` |
| Muted 2 (dates/meta) | `#6f6d69` | `--color-muted-2` |
| Placeholder (image bg) | `#efe8db` | `--color-placeholder` |

*Notes: `gold-text` exists separately from `gold-deep` because `gold-deep` as text on white/cream measures ~3:1, below WCAG AA's 4.5:1 — use `gold`/`gold-deep` freely as fills, borders, and text-on-dark; use `gold-text` only for text on light backgrounds. `muted`/`muted-2` were both darkened from earlier values that failed AA at the 12–14px sizes they're used at.*

### Typography
- **Heading/Display:** Libre Baskerville (Google Fonts, loaded async via preload+swap — never blocking)
- **Body:** din-next-w01-light, self-hosted from Wix's own font CDN (`static.parastorage.com`) via `@font-face` — this is intentional, not a Google Font, do not try to `@import` it from Google Fonts
- **Mood:** classic serif display + light sans body — editorial, not playful
- **CSS Import:**
```css
@import url("https://fonts.googleapis.com/css2?family=Libre+Baskerville:wght@400;700&display=swap");
```

### Key Effects
- `--radius-none: 0px` — sharp corners everywhere, **no exception**, including photo framing (a prior circular-medallion treatment was tried on the Mariages feature and explicitly reverted — see git history — the brand rule is flat rectangles only, confirmed by the project owner)
- Small heart-and-line "flourish" SVG motif under headings (`src/components/Flourish.astro`), reused as the site's one repeated signature element — do not introduce a second recurring motif
- `:focus-visible` outline in `--color-gold-deep`, 3px, 2px offset

### Avoid (Anti-patterns)
- Rounded corners or circular photo framing anywhere (confirmed reverted; flat rectangles are the rule)
- Any palette outside the ink/cream/gold tokens above — no pink, no vibrant/saturated accent colors
- Non-Libre-Baskerville display fonts, non-din-next body fonts, or any CJK/non-Latin font substitution
- Emoji as icons (site uses inline SVG throughout)
- Generic "cute puppy site" decoration standing in for real photography/credibility (explicit product principle — see `PRODUCT.md`)
- Puppies priced or badged like inventory/SKUs — breeding pairs are framed as relationships, not listings

### Pre-Delivery Checklist
- [ ] No emojis as icons (use inline SVG, matching existing icon style)
- [ ] Hover states with smooth transitions (150–300ms), matching existing `transition-colors`/`transition-transform` usage
- [ ] Text contrast ≥4.5:1 — reuse `gold-text`/`muted`/`muted-2`, don't invent new low-contrast grays
- [ ] Focus states visible for keyboard nav (`:focus-visible` already global — don't override it away)
- [ ] `prefers-reduced-motion` — not yet handled anywhere in the codebase; flag if adding new motion
- [ ] Responsive at real breakpoints already in use: mobile default, `sm`, `lg` — verify no horizontal overflow (recurring past bug on this project, e.g. fixed-width elements in flex rows)
- [ ] Sharp corners only — no `rounded-*` on any new element unless explicitly asked
